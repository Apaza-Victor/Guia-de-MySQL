Recursos para aprender MySQL

Herramientas

MySQL Workbench

Herramienta oficial de Oracle para modelado, diseño y administración de bases de datos MySQL. Incluye editor SQL, herramientas de migración, modelado ER y monitoreo de rendimiento.

Descargar

phpMyAdmin

Administrador web de MySQL escrito en PHP. Permite gestionar bases de datos, ejecutar consultas y administrar usuarios desde una interfaz gráfica accesible desde el navegador.

Visitar

DBeaver Community

Cliente de base de datos universal y gratuito compatible con MySQL. Ofrece editor SQL avanzado, explorador de objetos, generación de diagramas ER y soporte para múltiples gestores.

Descargar

XAMPP / WAMP / MAMP

Paquetes todo-en-uno que incluyen Apache, MySQL y PHP. Ideales para entornos de desarrollo local, permitiendo instalar y configurar un servidor MySQL completo en minutos.

Descargar

draw.io / dbdiagram.io

Herramientas gratuitas para diseñar diagramas entidad-relación y modelos de bases de datos. Facilitan la planificación visual de esquemas antes de implementarlos en MySQL.

HeidiSQL

Cliente de bases de datos gratuito y open source para Windows. Permite conectarse a MySQL y MariaDB, gestionar tablas, ejecutar consultas y exportar datos con una interfaz ligera y rápida.

Descargar

Adminer

Administrador de bases de datos web en un único archivo PHP. Ligero y seguro, permite gestionar MySQL desde el navegador con soporte para múltiples gestores, ideal para entornos de hosting.

Visitar

Beekeeper Studio Community

Cliente SQL gratuito y open source disponible para Windows, macOS y Linux. Ofrece editor SQL con autocompletado, explorador visual de tablas y compatibilidad con MySQL, PostgreSQL y SQLite.

Descargar

PlanetScale

Plataforma serverless compatible con MySQL con un plan gratuito. Perfecta para alojar bases de datos en la nube, usar branching (ramas de BD) y conectar aplicaciones sin gestionar servidores.

Visitar

Laragon

Entorno de desarrollo todo-en-uno para Windows, portable y ultrarrápido. Incluye Apache, Nginx, MySQL/MariaDB y PHP con arranque instantáneo. Mucho más ligero y rápido que XAMPP para desarrollo local.

Descargar

Docker + MySQL

Ejecuta MySQL en contenedores Docker con la imagen oficial del motor. Ideal para crear entornos reproducibles, probar versiones de MySQL en segundos y automatizar bases de datos de desarrollo.
