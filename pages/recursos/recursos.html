Recursos para aprender MySQL

Recopilación de recursos gratuitos para aprender MySQL: documentación oficial, cursos, plataformas de práctica y herramientas. Todos los enlaces han sido verificados y son de acceso libre.

Documentación oficial

MySQL Reference Manual

Documentación oficial completa de MySQL. Cubre todos los aspectos del motor, desde instalación hasta administración avanzada, con referencia detallada de todas las sentencias SQL, funciones y opciones de configuración.

Visitar

W3Schools MySQL

Tutorial interactivo de MySQL con ejemplos prácticos ejecutables en el navegador. Ideal para principiantes que quieren aprender la sintaxis SQL de forma visual y probar consultas sin instalar nada.

Visitar

MDN Databases

Guía de Mozilla Developer Network sobre bases de datos relacionales y SQL. Explica conceptos fundamentales con un enfoque claro y accesible para desarrolladores web.

Visitar

freeCodeCamp

Curso completo y gratuito de bases de datos relacionales y MySQL en YouTube. Incluye horas de contenido práctico con ejercicios y proyectos reales para afianzar los conocimientos.

Codecademy "Learn SQL"

Curso interactivo de SQL con ejercicios prácticos en el navegador. Cubre desde consultas básicas hasta avanzadas con una metodología hands-on que permite aprender haciendo.

Khan Academy Intro to SQL

Plataforma de aprendizaje móvil con curso de SQL interactivo. Perfecto para aprender sobre la marcha con lecciones cortas, cuestionarios y un editor de código integrado en la aplicación.

Plataformas de práctica

SQLZoo

Plataforma interactiva con tutoriales y ejercicios prácticos de SQL. Incluye bases de datos reales para practicar consultas SELECT, JOINs, subconsultas y más directamente en el navegador.

Visitar

HackerRank SQL

Plataforma de desafíos de SQL con problemas clasificados por dificultad. Ideal para preparar entrevistas técnicas y mejorar habilidades resolviendo problemas reales de bases de datos.

Visitar

LeetCode Database

Problemas de SQL para práctica y preparación de entrevistas técnicas. Ofrece desde consultas simples hasta desafíos complejos de optimización y diseño de bases de datos.

Visitar

DB Fiddle

Editor SQL online que soporta MySQL, PostgreSQL y SQLite. Ideal para probar consultas rápidamente, compartir fragmentos de código y colaborar con otros desarrolladores.

Visitar

SQLBolt

Tutorial interactivo de SQL con lecciones cortas y ejercicios prácticos. Cubre los conceptos esenciales de forma progresiva, ideal para quienes prefieren un aprendizaje estructurado.

Visitar

Programiz SQL Compiler

Compilador SQL online gratuito con editor integrado. Permite escribir y ejecutar consultas SQL en tiempo real, ideal para practicar sintaxis y probar conceptos sin configuración.

Visitar

Herramientas

MySQL Workbench

Herramienta oficial de Oracle para modelado, diseño y administración de bases de datos MySQL. Incluye editor SQL, herramientas de migración, modelado ER y monitoreo de rendimiento.

Descargar

phpMyAdmin

Administrador web de MySQL escrito en PHP. Permite gestionar bases de datos, ejecutar consultas y administrar usuarios desde una interfaz gráfica accesible desde el navegador.

Visitar

DBeaver Community

Cliente de base de datos universal y gratuito compatible con MySQL. Ofrece editor SQL avanzado, explorador de objetos, generación de diagramas ER y soporte para múltiples gestores.

Descargar

XAMPP / WAMP / MAMP

Paquetes todo-en-uno que incluyen Apache, MySQL y PHP. Ideales para entornos de desarrollo local, permitiendo instalar y configurar un servidor MySQL completo en minutos.

Descargar

draw.io / dbdiagram.io

Herramientas gratuitas para diseñar diagramas entidad-relación y modelos de bases de datos. Facilitan la planificación visual de esquemas antes de implementarlos en MySQL.
