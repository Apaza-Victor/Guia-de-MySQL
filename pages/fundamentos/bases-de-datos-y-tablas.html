Bases de datos y tablas

En MySQL, una base de datos es un contenedor lógico que agrupa tablas, vistas, procedimientos almacenados y otros objetos. Las tablas son la estructura fundamental donde se almacenan los datos organizados en filas y columnas. En esta sección aprenderás a crear, modificar y eliminar tanto bases de datos como tablas utilizando los comandos DDL (Data Definition Language).

CREATE DATABASE y USE

Para crear una base de datos se usa el comando CREATE DATABASE, seguido del nombre. Es recomendable especificar el conjunto de caracteres (character set) y la collation para garantizar la correcta manipulación de texto en diferentes idiomas. El comando USE selecciona la base de datos activa para las operaciones siguientes.

Crear y seleccionar una base de datos

SQL
CREATE DATABASE tienda
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_unicode_ci;

USE tienda;

CREATE TABLE

El comando CREATE TABLE define la estructura de una tabla especificando el nombre, las columnas con sus tipos de datos y las restricciones (constraints) como PRIMARY KEY, FOREIGN KEY, UNIQUE, NOT NULL, DEFAULT y CHECK. Cada tabla debe tener una clave primaria que identifique de forma única cada fila.

Crear tabla con constraints

SQL
CREATE TABLE estudiantes (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nombre VARCHAR(100) NOT NULL,
    email VARCHAR(150) UNIQUE NOT NULL,
    fecha_nacimiento DATE,
    promedio DECIMAL(3,2) DEFAULT 0.00 CHECK (promedio >= 0 AND promedio <= 20),
    activo BOOLEAN DEFAULT TRUE
);

ALTER TABLE

ALTER TABLE permite modificar la estructura de una tabla existente sin perder los datos. Se puede agregar (ADD), modificar (MODIFY) o eliminar (DROP COLUMN) columnas, así como agregar o eliminar constraints. Es una operación muy útil durante el desarrollo cuando la estructura inicial necesita ajustes.

Añadir y modificar columnas

SQL
-- Agregar una nueva columna
ALTER TABLE estudiantes
ADD COLUMN telefono VARCHAR(15) AFTER email;

-- Modificar el tipo de una columna existente
ALTER TABLE estudiantes
MODIFY COLUMN promedio DECIMAL(4,2);

-- Eliminar una columna
ALTER TABLE estudiantes
DROP COLUMN telefono;

DROP TABLE vs TRUNCATE

DROP TABLE elimina completamente la tabla y su estructura, liberando todo el espacio. TRUNCATE elimina todas las filas pero conserva la estructura, siendo más rápido que DELETE sin WHERE. Ambos comandos son operaciones DDL y no pueden revertirse con ROLLBACK (en la mayoría de motores).

Diferencias entre DROP y TRUNCATE

SQL
-- Elimina todas las filas pero conserva la estructura
TRUNCATE TABLE estudiantes;

-- Elimina toda la tabla incluyendo estructura
DROP TABLE estudiantes;

-- Elimina la base de datos completa
DROP DATABASE tienda;

SHOW TABLES y DESC

Los comandos SHOW TABLES y DESC (abreviatura de DESCRIBE) son esenciales para inspeccionar la estructura de una base de datos. SHOW TABLES lista todas las tablas en la base de datos activa, mientras que DESC muestra la estructura detallada de una tabla incluyendo tipo de datos, nulabilidad, valores por defecto y claves.

Inspeccionar la base de datos

SQL
SHOW TABLES;

DESC estudiantes;

Siempre usa utf8mb4 como character set y utf8mb4_unicode_ci como collation para tus bases de datos. Esto garantiza compatibilidad con emojis, caracteres acentuados y prácticamente cualquier idioma del mundo.

Ten mucho cuidado con DROP TABLE y DROP DATABASE en producción. Estos comandos eliminan los datos de forma permanente. Siempre haz un backup antes de ejecutarlos y verifica dos veces el nombre de la tabla o base de datos.

Una buena práctica de diseño es incluir siempre una columna id con AUTO_INCREMENT como clave primaria y usar NOT NULL en columnas que son obligatorias para la lógica del negocio. También es recomendable definir valores DEFAULT adecuados en lugar de permitir NULL.
