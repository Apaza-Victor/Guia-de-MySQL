Instalación y configuración de MySQL

Existen múltiples formas de instalar MySQL dependiendo del sistema operativo y del entorno de desarrollo que prefieras. Desde paquetes todo-en-uno como XAMPP hasta el instalador oficial de MySQL, en esta guía cubriremos las opciones más comunes para que puedas empezar a trabajar con bases de datos relacionales en pocos minutos.

Instalación en Windows

En Windows, la forma más sencilla es usar el instalador oficial de MySQL (MySQL Installer), que permite elegir qué componentes instalar: servidor, cliente, workbench, conectores, etc. También puedes optar por paquetes integrados como XAMPP o WAMP que incluyen Apache, MySQL y PHP en un solo instalador, ideales para entornos de desarrollo web.

Verificar la instalación

Terminal
mysql --version

Instalación en Linux

En distribuciones basadas en Debian/Ubuntu, MySQL se instala fácilmente con el gestor de paquetes apt. En sistemas basados en Red Hat como Fedora o CentOS, se utiliza dnf o yum. Los repositorios oficiales de MySQL también ofrecen versiones actualizadas para las distribuciones más populares.

Instalar MySQL en Ubuntu

Terminal
sudo apt update
sudo apt install mysql-server

Instalación en macOS

En macOS, el método más recomendado es usar Homebrew, el gestor de paquetes para macOS. También puedes descargar el DMG oficial desde el sitio de MySQL, que incluye un asistente gráfico de instalación. Otra opción es usar MAMP, similar a XAMPP en Windows.

Instalar MySQL con Homebrew

Terminal
brew install mysql

Primeros pasos: conectar a MySQL

Una vez instalado, puedes conectarte al servidor MySQL usando el cliente de línea de comandos con el usuario root. Durante la instalación se te pedirá establecer una contraseña para el usuario root. Si usas XAMPP, el usuario root no tiene contraseña por defecto.

Conectar al servidor MySQL

Terminal
mysql -u root -p

Si eres principiante, usa XAMPP en Windows o MAMP en macOS. Incluyen phpMyAdmin, una interfaz gráfica web que facilita la administración de bases de datos sin escribir comandos SQL.

Nunca uses el usuario root sin contraseña en un entorno de producción. Siempre establece una contraseña segura y crea usuarios con privilegios limitados para cada aplicación.

Después de instalar MySQL, ejecuta mysql_secure_installation para mejorar la seguridad: establecer contraseña de root, eliminar usuarios anónimos, deshabilitar login remoto de root y eliminar bases de datos de prueba.
