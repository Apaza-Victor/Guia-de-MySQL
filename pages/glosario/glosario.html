Glosario de términos SQL / MySQL

Diccionario de términos y conceptos de SQL y MySQL ordenados alfabéticamente. Cada término incluye una definición clara y concisa en español.

ABCDEF GHIJKL MNOPQR STUVWX YZ

A

ACID

Acrónimo de Atomicidad, Consistencia, Aislamiento y Durabilidad. Conjunto de propiedades que garantizan que las transacciones de bases de datos se procesen de manera fiable. InnoDB es el motor de MySQL que soporta transacciones ACID completamente.

Aggregate functions

Funciones agregadas que realizan cálculos sobre un conjunto de filas y devuelven un único resultado. Las principales son SUM(), AVG(), COUNT(), MIN() y MAX().

Alias

Nombre temporal asignado a una columna o tabla dentro de una consulta SQL mediante la palabra clave AS. Mejora la legibilidad y permite referenciar nombres calculados.

ALTER

Sentencia DDL utilizada para modificar la estructura de una tabla existente. Permite agregar, eliminar o modificar columnas, así como cambiar restricciones e índices. Ejemplo: ALTER TABLE usuarios ADD email VARCHAR(100);

AUTO_INCREMENT

Atributo de columna en MySQL que genera automáticamente un valor numérico secuencial único para cada nueva fila insertada. Se usa comúnmente para claves primarias.

B

B-tree

Estructura de datos de árbol balanceado utilizada por MySQL para los índices. Permite búsquedas rápidas, inserciones y eliminaciones en tiempo logarítmico. Es el tipo de índice predeterminado en InnoDB y MyISAM.

BACKUP

Copia de seguridad de una base de datos. MySQL ofrece herramientas como mysqldump para realizar backups lógicos, y opciones de backup físico como la copia de archivos de datos.

BETWEEN

Operador SQL utilizado para filtrar resultados dentro de un rango inclusive. Ejemplo: SELECT * FROM productos WHERE precio BETWEEN 10 AND 50;

BLOB

Tipo de dato binario que almacena objetos grandes como imágenes, archivos o datos multimedia. Puede ser TINYBLOB, BLOB, MEDIUMBLOB o LONGBLOB según la capacidad.

BOOLEAN

Tipo de dato lógico que puede tener valores verdadero (TRUE o 1) o falso (FALSE o 0). En MySQL, BOOL y BOOLEAN son sinónimos de TINYINT(1).

C

CASCADE

Opción de integridad referencial que propaga automáticamente las operaciones de actualización o eliminación de una tabla padre a las tablas hijas. Ejemplo: ON DELETE CASCADE elimina en cascada los registros relacionados.

CHAR

Tipo de dato de cadena de longitud fija. Almacena exactamente la longitud especificada, rellenando con espacios a la derecha si es necesario. Más rápido que VARCHAR para longitudes cortas y fijas.

CHECK

Restricción que limita los valores que pueden insertarse en una columna según una condición. Aunque MySQL la acepta sintácticamente, solo la evalúa en versiones recientes con determinados motores.

Clave foránea (FOREIGN KEY)

Campo o combinación de campos que establece una relación entre dos tablas, referenciando la clave primaria de otra tabla. Garantiza la integridad referencial de los datos.

Clave primaria (PRIMARY KEY)

Columna o conjunto de columnas que identifica de forma única cada fila de una tabla. Debe ser única y no nula. Cada tabla puede tener solo una clave primaria.

COMMIT

Sentencia que guarda permanentemente todas las modificaciones realizadas en la transacción actual. Una vez ejecutada, los cambios no pueden revertirse con ROLLBACK.

CONSTRAINT

Palabra clave utilizada para definir restricciones en las columnas de una tabla, como PRIMARY KEY, FOREIGN KEY, UNIQUE, CHECK y NOT NULL.

CREATE

Sentencia DDL utilizada para crear nuevos objetos en la base de datos, como bases de datos, tablas, vistas, índices, procedimientos almacenados y funciones.

CROSS JOIN

Tipo de JOIN que produce el producto cartesiano de dos tablas, combinando cada fila de la primera tabla con todas las filas de la segunda. También conocido como JOIN cruzado.

D

DATABASE

Conjunto organizado de datos estructurados almacenados electrónicamente. En MySQL, se crea con CREATE DATABASE y puede contener múltiples tablas, vistas, procedimientos y otros objetos.

DATE

Tipo de dato que almacena fechas en formato YYYY-MM-DD. El rango soportado va desde 1000-01-01 hasta 9999-12-31.

DATETIME

Tipo de dato que almacena fecha y hora en formato YYYY-MM-DD HH:MM:SS. Combina las funcionalidades de DATE y TIME en un solo campo.

DECIMAL

Tipo de dato numérico de precisión exacta, ideal para valores monetarios y cálculos financieros donde no se toleran errores de redondeo. Ejemplo: DECIMAL(10,2) almacena números con 2 decimales.

DEFAULT

Valor predeterminado asignado a una columna cuando no se especifica un valor en la inserción. Se define al crear o modificar la tabla con la cláusula DEFAULT.

DELETE

Sentencia DML que elimina una o más filas de una tabla. Si no se usa WHERE, elimina todas las filas. Ejemplo: DELETE FROM usuarios WHERE id = 5;

DISTINCT

Palabra clave que elimina filas duplicadas del resultado de una consulta. Ejemplo: SELECT DISTINCT ciudad FROM clientes;

DROP

Sentencia DDL que elimina permanentemente objetos de la base de datos como tablas, bases de datos, vistas o índices. Ejemplo: DROP TABLE usuarios;

E

ENUM

Tipo de dato que permite definir una columna con un conjunto fijo de valores permitidos. Ejemplo: estado ENUM('activo', 'inactivo', 'suspendido'). Optimiza el almacenamiento al usar índices internos.

Entity (Entidad)

Objeto del mundo real representado en una base de datos, como una persona, producto o pedido. En el modelo entidad-relación, las entidades se convierten en tablas dentro del esquema relacional.

ER diagram (Diagrama ER)

Representación gráfica de las entidades y relaciones de una base de datos. Muestra tablas, atributos, claves y las conexiones entre ellas, facilitando el diseño conceptual del esquema.

EVENT

Tarea programada que se ejecuta automáticamente en MySQL según un calendario definido. Similar a los cron jobs de Linux, permite automatizar tareas como limpieza de datos o generación de informes.

EXPLAIN

Sentencia que muestra el plan de ejecución de una consulta SQL. Fundamental para optimizar consultas lentas, ya que revela cómo MySQL accede a las tablas y qué índices utiliza.

F

FLOAT

Tipo de dato numérico de coma flotante de precisión simple. Almacena números con decimales pero puede introducir errores de redondeo. Para precisión exacta se recomienda DECIMAL.

FOREIGN KEY

Véase Clave foránea. Restricción que vincula una columna de una tabla con la clave primaria de otra tabla para mantener la integridad referencial.

FULLTEXT

Tipo de índice especializado para búsquedas de texto completo en columnas de tipo CHAR, VARCHAR o TEXT. Permite búsquedas avanzadas con MATCH...AGAINST.

FUNCTION

Bloque de código SQL reutilizable que acepta parámetros, realiza operaciones y devuelve un valor. En MySQL existen funciones incorporadas y funciones definidas por el usuario (UDF).

G

GET_FORMAT

Función de MySQL que devuelve una cadena de formato para usar con DATE_FORMAT y STR_TO_DATE. Admite valores predefinidos como DATE, TIME, DATETIME y TIMESTAMP.

GRANT

Sentencia DCL utilizada para otorgar permisos y privilegios a usuarios de MySQL. Ejemplo: GRANT SELECT, INSERT ON basedatos.* TO 'usuario'@'localhost';

GROUP BY

Cláusula que agrupa filas que tienen los mismos valores en columnas especificadas, permitiendo aplicar funciones de agregación a cada grupo. Ejemplo: SELECT ciudad, COUNT(*) FROM clientes GROUP BY ciudad;

H

HASH index

Tipo de índice basado en una tabla hash, óptimo para búsquedas de igualdad (= o IN). En MySQL, solo está disponible para el motor MEMORY y NDB Cluster.

HAVING

Cláusula que filtra grupos creados por GROUP BY según una condición. Similar a WHERE pero aplica a nivel de grupos, no de filas individuales. Ejemplo: HAVING COUNT(*) > 5.

I

IF

Función de control de flujo en MySQL que evalúa una condición y devuelve un valor si es verdadera y otro si es falsa. Ejemplo: IF(edad >= 18, 'Mayor', 'Menor').

IN

Operador que verifica si un valor está dentro de un conjunto de valores. Ejemplo: SELECT * FROM productos WHERE categoria IN ('electronica', 'hogar');

INDEX

Estructura de datos que mejora la velocidad de las operaciones de búsqueda en una tabla. Similar al índice de un libro, permite localizar filas sin escanear toda la tabla.

INNER JOIN

Tipo de JOIN que devuelve solo las filas que tienen coincidencia en ambas tablas. Es el tipo de JOIN más común y se usa para combinar datos relacionados de dos tablas.

INSERT

Sentencia DML que agrega nuevas filas a una tabla. Ejemplo: INSERT INTO usuarios (nombre, email) VALUES ('Juan', 'juan@email.com');

INT

Tipo de dato numérico entero que almacena números sin decimales. Puede ser TINYINT, SMALLINT, MEDIUMINT, INT o BIGINT, variando el rango de valores y el espacio de almacenamiento.

Integridad referencial

Principio que garantiza que las relaciones entre tablas se mantengan consistentes. Evita huérfanos asegurando que todo valor de clave foránea exista como clave primaria en la tabla referenciada.

IS NULL

Operador que verifica si un valor es nulo (NULL). No puede usarse = NULL porque NULL no es un valor, sino la ausencia de valor. Ejemplo: WHERE telefono IS NULL.

J

JOIN

Operación que combina columnas de dos o más tablas basándose en una condición relacionada. Los tipos principales son INNER, LEFT, RIGHT, FULL y CROSS JOIN.

JSON

Tipo de dato que permite almacenar documentos JSON en MySQL. Soporta funciones nativas para manipular, consultar y extraer datos JSON, incluyendo JSON_EXTRACT() e índices virtuales.

K

KEY

Sinónimo de INDEX en MySQL. Se usa para crear índices en una tabla. También aparece en definiciones de PRIMARY KEY, FOREIGN KEY y UNIQUE KEY.

KEY_BLOCK_SIZE

Opción de compresión de índices en InnoDB que especifica el tamaño de bloque para índices comprimidos. Reduce el uso de espacio en disco a costa de mayor uso de CPU.

L

LEFT JOIN

Tipo de JOIN que devuelve todas las filas de la tabla izquierda y las coincidencias de la tabla derecha. Si no hay coincidencia, las columnas de la derecha aparecen como NULL.

LIKE

Operador utilizado en búsquedas de patrones en cadenas. Usa % como comodín para múltiples caracteres y _ para un solo carácter. Ejemplo: WHERE nombre LIKE 'Ana%'.

LIMIT

Cláusula que restringe el número de filas devueltas por una consulta. Ejemplo: SELECT * FROM productos LIMIT 10; devuelve solo las primeras 10 filas.

LOG

Archivos de registro que MySQL genera para registrar actividades, errores, consultas lentas y transacciones. Son fundamentales para auditoría, depuración y recuperación de datos.

M

InnoDB

Motor de almacenamiento predeterminado en MySQL desde la versión 5.5. Soporta transacciones ACID, claves foráneas, control de concurrencia multiversión (MVCC) y recuperación ante fallos.

MATCH...AGAINST

Función de búsqueda de texto completo que utiliza índices FULLTEXT. Permite búsquedas por relevancia, modo booleano y expansión de consultas. Ejemplo: WHERE MATCH(titulo) AGAINST('MySQL' IN BOOLEAN MODE).

Memory

Motor de almacenamiento que mantiene los datos en memoria RAM. Ofrece velocidades extremadamente rápidas pero los datos se pierden al reiniciar el servidor. Ideal para tablas temporales y cachés.

MyISAM

Motor de almacenamiento anterior a InnoDB, conocido por su simplicidad y buen rendimiento en lecturas. No soporta transacciones ACID ni claves foráneas. Fue el motor predeterminado hasta MySQL 5.4.

mysqldump

Herramienta de línea de comandos para realizar backups lógicos de bases de datos MySQL. Genera archivos SQL con sentencias CREATE y INSERT que permiten recrear la base de datos completamente.

N

Normalización 1FN, 2FN, 3FN

Proceso de diseño de bases de datos que elimina redundancias y dependencias. 1FN elimina grupos repetitivos, 2FN elimina dependencias parciales, 3FN elimina dependencias transitivas. El objetivo es un diseño eficiente y consistente.

NOT NULL

Restricción que impide que una columna almacene valores nulos (NULL). Garantiza que toda fila tenga un valor obligatorio en esa columna.

O

OFFSET

Cláusula utilizada junto con LIMIT para especificar desde qué fila comenzar a devolver resultados. Ejemplo: LIMIT 10 OFFSET 20 devuelve 10 filas saltando las primeras 20.

ON DELETE CASCADE

Opción de clave foránea que elimina automáticamente las filas hijas cuando se elimina la fila padre correspondiente. Útil para mantener la integridad referencial sin acciones manuales.

OR

Operador lógico que combina condiciones en SQL. Devuelve verdadero si al menos una de las condiciones es verdadera. Ejemplo: WHERE ciudad = 'Madrid' OR ciudad = 'Barcelona'.

ORDER BY

Cláusula que ordena los resultados de una consulta de forma ascendente (ASC) o descendente (DESC). Ejemplo: ORDER BY precio DESC.

P

PARTITION

Técnica que divide una tabla grande en segmentos más pequeños llamados particiones, basándose en una regla como rango, lista o hash. Mejora el rendimiento y facilita la administración de datos masivos.

Prepared statements

Consultas SQL precompiladas que separan el código SQL de los datos. Mejoran la seguridad al prevenir inyección SQL y optimizan el rendimiento cuando se ejecutan múltiples veces.

PRIMARY KEY

Véase Clave primaria. Restricción que identifica de forma única cada fila de una tabla. Una tabla puede tener solo una clave primaria, que puede ser simple o compuesta.

PROCEDURE

Bloque de código SQL almacenado que puede aceptar parámetros y ejecutar operaciones complejas. A diferencia de las funciones, no está obligado a devolver un valor.

Q

Query

Consulta o petición que se envía a la base de datos para recuperar, insertar, actualizar o eliminar datos. En MySQL se escribe utilizando el lenguaje SQL.

R

REGEXP

Operador que realiza búsquedas mediante expresiones regulares en MySQL. Más potente que LIKE, permite patrones complejos. Ejemplo: WHERE email REGEXP '^[a-z]+@'.

REPLACE

Sentencia similar a INSERT pero que reemplaza un registro existente si encuentra un conflicto de clave primaria o única. Si no existe, inserta una nueva fila.

REVOKE

Sentencia DCL utilizada para retirar permisos y privilegios previamente otorgados a un usuario. Ejemplo: REVOKE DELETE ON basedatos.* FROM 'usuario'@'localhost';

RIGHT JOIN

Tipo de JOIN que devuelve todas las filas de la tabla derecha y las coincidencias de la tabla izquierda. Es el inverso de LEFT JOIN.

ROLLBACK

Sentencia que deshace todas las modificaciones realizadas en la transacción actual, devolviendo la base de datos al estado anterior al COMMIT o BEGIN.

S

SAVEPOINT

Punto de control dentro de una transacción que permite deshacer solo una parte de la transacción sin afectar al resto. Se usa con ROLLBACK TO SAVEPOINT.

SELECT

Sentencia DML fundamental para recuperar datos de una o más tablas. Es la instrucción más utilizada en SQL y admite múltiples cláusulas como WHERE, JOIN, GROUP BY, HAVING y ORDER BY.

SET

Sentencia utilizada para asignar valores a variables o modificar configuraciones del servidor. Ejemplos: SET @variable = 10; o SET NAMES utf8mb4;

SHOW

Sentencia que muestra información sobre objetos de la base de datos. Ejemplos: SHOW DATABASES;, SHOW TABLES;, SHOW CREATE TABLE usuarios;

SSL

Protocolo de cifrado que MySQL soporta para conexiones seguras entre cliente y servidor. Garantiza que los datos transferidos estén encriptados y protegidos contra interceptaciones.

SUBQUERY

Consulta anidada dentro de otra consulta SQL. Puede usarse en cláusulas SELECT, FROM, WHERE, HAVING y con operadores como IN, EXISTS, ANY y ALL.

SUM

Función de agregación que calcula la suma total de los valores de una columna numérica. Ejemplo: SELECT SUM(total) FROM pedidos;

T

TABLE

Estructura fundamental de almacenamiento en una base de datos relacional. Organiza los datos en filas (registros) y columnas (campos), con un esquema definido que especifica los tipos de datos y restricciones.

TEXT

Tipo de dato para almacenar cadenas de texto largas. Puede ser TINYTEXT, TEXT, MEDIUMTEXT o LONGTEXT, con capacidad desde 255 bytes hasta 4 GB.

TIMESTAMP

Tipo de dato que almacena fecha y hora con zona horaria. Se actualiza automáticamente al valor actual en inserciones y modificaciones si se define con DEFAULT CURRENT_TIMESTAMP.

TRANSACTION

Unidad de trabajo compuesta por una o más operaciones SQL que se ejecutan de forma atómica. Las transacciones siguen las propiedades ACID y se controlan con COMMIT y ROLLBACK.

TRIGGER

Bloque de código SQL que se ejecuta automáticamente en respuesta a eventos como INSERT, UPDATE o DELETE sobre una tabla. Útil para auditoría, validaciones y actualizaciones en cascada.

TRUNCATE

Sentencia DDL que elimina todas las filas de una tabla de forma rápida, reiniciando además los contadores AUTO_INCREMENT. Es más rápido que DELETE sin WHERE pero no permite condiciones.

Types (data)

Categorías de datos que MySQL puede almacenar: numéricos (INT, DECIMAL, FLOAT), cadenas (CHAR, VARCHAR, TEXT), fecha/hora (DATE, DATETIME, TIMESTAMP) y especiales (JSON, ENUM, BLOB).

U

UNION

Operador que combina los resultados de dos o más consultas SELECT en un único conjunto de resultados, eliminando filas duplicadas por defecto. UNION ALL conserva los duplicados.

UNIQUE

Restricción que garantiza que todos los valores de una columna o combinación de columnas sean distintos entre sí. Permite valores NULL, a diferencia de la clave primaria.

UPDATE

Sentencia DML que modifica los valores de una o más columnas en filas existentes. Ejemplo: UPDATE usuarios SET email = 'nuevo@email.com' WHERE id = 1;

USER

Cuenta que puede conectarse al servidor MySQL. Cada usuario tiene un nombre y un host asociado, y puede tener privilegios específicos gestionados con GRANT y REVOKE.

USING

Cláusula alternativa a ON en JOIN cuando las columnas de enlace tienen el mismo nombre en ambas tablas. Ejemplo: JOIN pedidos USING (id_cliente).

V

VALUES

Palabra clave utilizada en la sentencia INSERT para especificar los datos a insertar. También se usa en SHOW COLUMNS para mostrar los valores permitidos de un ENUM.

VARCHAR

Tipo de dato de cadena de longitud variable. Almacena solo los caracteres introducidos más un prefijo de longitud. Más eficiente en espacio que CHAR para cadenas de longitud variable.

VIEW

Tabla virtual basada en el resultado de una consulta SELECT. No almacena datos físicamente sino que muestra una perspectiva de los datos subyacentes. Útil para seguridad y simplificación.

W

WHERE

Cláusula que filtra filas según una condición especificada. Es la forma principal de restringir resultados en consultas SELECT, UPDATE y DELETE.

WITH

Cláusula que define una expresión de tabla común (CTE), una tabla temporal con nombre que existe dentro del ámbito de una consulta. Mejora la legibilidad de consultas complejas.

WORK

Palabra clave opcional en las sentencias de transacción BEGIN WORK, COMMIT WORK y ROLLBACK WORK. Especificada por el estándar SQL pero no tiene efecto funcional en MySQL.

X

XA transactions

Protocolo de transacciones distribuidas que permite coordinar transacciones entre múltiples gestores de bases de datos. MySQL soporta XA para garantizar consistencia en entornos heterogéneos.

Y

YEAR

Tipo de dato que almacena años en formato de 4 dígitos. Rango soportado: 1901 a 2155. Puede almacenarse como string o número.

Z

ZEROFILL

Atributo de columna numérica que rellena con ceros a la izquierda hasta completar la longitud definida. Ejemplo: INT(5) ZEROFILL muestra 00005 en lugar de 5.
