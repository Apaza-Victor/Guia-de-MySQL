Operadores de conjunto (UNION, INTERSECT, EXCEPT)

Los operadores de conjunto permiten combinar los resultados de dos o más consultas SELECT en un solo resultado. A diferencia de los JOINs que combinan columnas horizontalmente, los operadores de conjunto apilan filas verticalmente o encuentran coincidencias entre conjuntos.

Reglas fundamentales

Para usar cualquier operador de conjunto, ambas consultas deben cumplir:

  • Mismo número de columnas en el SELECT.
  • Tipos de datos compatibles columna por columna.
  • El orden de las columnas determina la correspondencia (no los nombres).
SQL
-- Sintaxis general
SELECT columna1, columna2 FROM tabla1
OPERADOR
SELECT columna1, columna2 FROM tabla2
ORDER BY columna1;

UNION vs UNION ALL

UNION combina resultados de dos consultas eliminando duplicados. UNION ALL los combina sin eliminar duplicados (más rápido).

SQL
-- Datos de ejemplo
CREATE TABLE clientes_2023 (
    id INT, nombre VARCHAR(50), email VARCHAR(100)
);
CREATE TABLE clientes_2024 (
    id INT, nombre VARCHAR(50), email VARCHAR(100)
);

INSERT INTO clientes_2023 VALUES
(1, 'Ana López', 'ana@email.com'),
(2, 'Carlos Ruiz', 'carlos@email.com'),
(3, 'María Díaz', 'maria@email.com');

INSERT INTO clientes_2024 VALUES
(2, 'Carlos Ruiz', 'carlos@email.com'),
(3, 'María Díaz', 'maria@email.com'),
(4, 'Pedro Gómez', 'pedro@email.com');

-- UNION ALL: todos los registros (incluye duplicados)
SELECT nombre, email FROM clientes_2023
UNION ALL
SELECT nombre, email FROM clientes_2024;

-- UNION: sin duplicados
SELECT nombre, email FROM clientes_2023
UNION
SELECT nombre, email FROM clientes_2024;
ConsultaFilasIncluye duplicados?
UNION ALL6Sí (Carlos y María aparecen 2 veces)
UNION4No

Usa UNION ALL cuando sepas que no hay duplicados o cuando no te importen. Es significativamente más rápido que UNION porque evita la operación de eliminación de duplicados.

UNION con ORDER BY y LIMIT

Puedes ordenar el resultado final con ORDER BY al final. Si necesitas orden o límite por cada consulta individual, usa subconsultas o paréntesis:

SQL
-- ORDER BY global (al final)
SELECT id, nombre FROM clientes_2023
UNION
SELECT id, nombre FROM clientes_2024
ORDER BY nombre ASC;

-- LIMIT por consulta individual (con paréntesis)
(SELECT * FROM clientes_2023 ORDER BY id DESC LIMIT 2)
UNION
(SELECT * FROM clientes_2024 ORDER BY id DESC LIMIT 2);

INTERSECT

INTERSECT devuelve solo las filas que existen en ambas consultas. Está disponible desde MySQL 8.0.31:

SQL
-- Clientes que están en ambos años
SELECT nombre, email FROM clientes_2023
INTERSECT
SELECT nombre, email FROM clientes_2024;

-- Resultado: Carlos Ruiz y María Díaz (2 filas)

INTERSECT y EXCEPT están disponibles desde MySQL 8.0.31 (MariaDB los soporta desde versiones anteriores). Si usas MySQL 8.0.30 o inferior, puedes simularlos con IN, EXISTS o JOIN.

EXCEPT (o MINUS)

EXCEPT devuelve las filas de la primera consulta que no existen en la segunda. En Oracle se llama MINUS:

SQL
-- Clientes de 2023 que NO están en 2024
SELECT nombre, email FROM clientes_2023
EXCEPT
SELECT nombre, email FROM clientes_2024;

-- Resultado: Ana López (1 fila)

-- Simular EXCEPT en MySQL < 8.0.31
SELECT c2023.* FROM clientes_2023 c2023
WHERE NOT EXISTS (
    SELECT 1 FROM clientes_2024 c2024
    WHERE c2024.email = c2023.email
);

Ejemplo práctico: reporte de ventas

SQL
-- Productos más vendidos en 2023 y 2024
(SELECT '2023' AS año, p.nombre, SUM(v.cantidad) AS total
 FROM ventas_2023 v JOIN productos p ON v.producto_id = p.id
 GROUP BY p.nombre
 ORDER BY total DESC LIMIT 5)

UNION ALL

(SELECT '2024' AS año, p.nombre, SUM(v.cantidad) AS total
 FROM ventas_2024 v JOIN productos p ON v.producto_id = p.id
 GROUP BY p.nombre
 ORDER BY total DESC LIMIT 5)
ORDER BY año, total DESC;
