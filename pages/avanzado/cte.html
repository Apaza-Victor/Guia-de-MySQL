CTEs y consultas recursivas (WITH)

Una Common Table Expression (CTE) es una consulta temporal con nombre que puedes referenciar dentro de una sentencia SELECT, INSERT, UPDATE o DELETE. Se definen con la cláusula WITH y hacen que el SQL sea más legible, modular y fácil de mantener.

¿Qué es una CTE?

Una CTE actúa como una vista temporal que existe solo durante la ejecución de la consulta. A diferencia de una subconsulta, puedes referenciar una CTE múltiples veces dentro de la misma sentencia, lo que evita duplicación y mejora la claridad del código.

SQL
-- Sintaxis básica de CTE
WITH nombre_cte AS (
    SELECT columna1, columna2
    FROM tabla
    WHERE condicion
)
SELECT * FROM nombre_cte;

CTE simple

Supongamos una tabla empleados y queremos obtener los empleados con salario superior al promedio de su departamento:

SQL
-- Datos de ejemplo
CREATE TABLE empleados (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nombre VARCHAR(50),
    departamento VARCHAR(50),
    salario DECIMAL(10,2)
);

INSERT INTO empleados (nombre, departamento, salario) VALUES
('Ana López', 'Ventas', 3500),
('Carlos Ruiz', 'Ventas', 4200),
('María Díaz', 'IT', 5000),
('Pedro Gómez', 'IT', 4800),
('Laura Torres', 'Ventas', 3100),
('Roberto Vega', 'IT', 5200);

-- CTE: promedio por departamento
WITH promedio_depto AS (
    SELECT departamento, AVG(salario) AS salario_promedio
    FROM empleados
    GROUP BY departamento
)
SELECT e.nombre, e.departamento, e.salario, p.salario_promedio
FROM empleados e
JOIN promedio_depto p ON e.departamento = p.departamento
WHERE e.salario > p.salario_promedio;

Las CTE hacen que las consultas complejas sean más legibles que las subconsultas anidadas, especialmente cuando necesitas referenciar el mismo resultado varias veces.

Múltiples CTEs

Puedes definir varias CTEs separadas por comas. Cada una puede referenciar a las anteriores:

SQL
WITH
ventas_2023 AS (
    SELECT cliente_id, SUM(total) AS total_2023
    FROM pedidos WHERE YEAR(fecha) = 2023
    GROUP BY cliente_id
),
ventas_2024 AS (
    SELECT cliente_id, SUM(total) AS total_2024
    FROM pedidos WHERE YEAR(fecha) = 2024
    GROUP BY cliente_id
)
SELECT 
    c.nombre,
    v2023.total_2023,
    v2024.total_2024,
    (v2024.total_2024 - v2023.total_2023) AS crecimiento
FROM clientes c
LEFT JOIN ventas_2023 v2023 ON c.id = v2023.cliente_id
LEFT JOIN ventas_2024 v2024 ON c.id = v2024.cliente_id
ORDER BY crecimiento DESC;

CTE recursiva

Las CTEs recursivas se utilizan para trabajar con datos jerárquicos como árboles de categorías, organigramas o rutas. Una CTE recursiva tiene dos partes: un ancla (consulta base) y una parte recursiva que se une al resultado anterior con UNION ALL.

SQL
-- Estructura jerárquica: categorías
CREATE TABLE categorias (
    id INT PRIMARY KEY,
    nombre VARCHAR(100),
    padre_id INT NULL,
    FOREIGN KEY (padre_id) REFERENCES categorias(id)
);

INSERT INTO categorias VALUES
(1, 'Electrónica', NULL),
(2, 'Computadoras', 1),
(3, 'Celulares', 1),
(4, 'Laptops', 2),
(5, 'Accesorios PC', 2),
(6, 'Tablets', 3),
(7, 'Auriculares', 5);

-- CTE recursiva: árbol completo con nivel
WITH RECURSIVE arbol AS (
    -- Ancla: nodos raíz (sin padre)
    SELECT id, nombre, padre_id, 0 AS nivel, CAST(nombre AS CHAR(200)) AS ruta
    FROM categorias WHERE padre_id IS NULL
    
    UNION ALL
    
    -- Parte recursiva: hijos
    SELECT c.id, c.nombre, c.padre_id, a.nivel + 1,
           CONCAT(a.ruta, ' > ', c.nombre)
    FROM categorias c
    JOIN arbol a ON c.padre_id = a.id
)
SELECT * FROM arbol ORDER BY ruta;

Las CTEs recursivas deben incluir la palabra clave RECURSIVE justo después de WITH (MySQL 8.0+). Sin ella, obtendrás un error de sintaxis. Siempre asegúrate de que la parte recursiva tenga una condición de terminación para evitar bucles infinitos.

Limitaciones de las CTEs

  • Las CTEs existen solo durante la ejecución de la consulta — no se almacenan en disco.
  • No se pueden referenciar desde otras consultas ni desde procedimientos almacenados como objetos persistentes.
  • El rendimiento de una CTE recursiva puede degradarse con conjuntos de datos muy grandes (millones de filas).
  • MySQL limita la recursión a 1000 iteraciones por defecto (cte_max_recursion_depth).
