Procedimientos almacenados

Un procedimiento almacenado (stored procedure) es un bloque de código SQL con nombre que se almacena en el servidor de base de datos. Puede aceptar parámetros, ejecutar consultas, contener lógica condicional y bucles, y devolver múltiples conjuntos de resultados. Los procedimientos se invocan con la instrucción CALL.

CREATE PROCEDURE

La sintaxis básica para crear un procedimiento requiere especificar el nombre, los parámetros (opcionales) y el cuerpo del procedimiento delimitado por BEGIN ... END:

SQL
DELIMITER $$

CREATE PROCEDURE obtener_empleados_por_depto(IN depto_nombre VARCHAR(50))
BEGIN
    SELECT e.id, e.nombre, e.apellido, e.salario
    FROM empleados e
    INNER JOIN departamentos d ON e.depto_id = d.id
    WHERE d.nombre = depto_nombre
    ORDER BY e.apellido;
END$$

DELIMITER ;

Parámetros IN, OUT, INOUT

MySQL ofrece tres tipos de parámetros:

TipoFunciónEjemplo
INEl procedimiento recibe un valor (parámetro de entrada)IN depto_nombre VARCHAR(50)
OUTEl procedimiento asigna un valor que la llamada recibeOUT total INT
INOUTEl procedimiento recibe un valor y puede modificarloINOUT contador INT
SQL
DELIMITER $$

CREATE PROCEDURE contar_empleados(IN depto_id INT, OUT total INT)
BEGIN
    SELECT COUNT(*) INTO total
    FROM empleados
    WHERE depto_id = depto_id;
END$$

DELIMITER ;

-- Llamada
CALL contar_empleados(3, @total);
SELECT @total AS total_empleados;

Variables y estructuras de control

Dentro de un procedimiento puedes declarar variables locales con DECLARE y usar estructuras como IF, CASE, WHILE, LOOP y REPEAT:

SQL
DELIMITER $$

CREATE PROCEDURE calcular_bono_anual(IN empleado_id INT, OUT bono DECIMAL(10,2))
BEGIN
    DECLARE salario_actual DECIMAL(10,2);
    DECLARE antiguedad INT;

    -- Obtener datos del empleado
    SELECT salario, TIMESTAMPDIFF(YEAR, fecha_contratacion, CURDATE())
    INTO salario_actual, antiguedad
    FROM empleados WHERE id = empleado_id;

    -- Calcular bono según antigüedad
    IF antiguedad >= 10 THEN
        SET bono = salario_actual * 0.20;
    ELSEIF antiguedad >= 5 THEN
        SET bono = salario_actual * 0.10;
    ELSE
        SET bono = salario_actual * 0.05;
    END IF;
END$$

DELIMITER ;

WHILE y bucles

SQL
DELIMITER $$

CREATE PROCEDURE generar_serie(IN limite INT)
BEGIN
    DECLARE contador INT DEFAULT 1;
    DECLARE resultado TEXT DEFAULT '';

    WHILE contador <= limite DO
        SET resultado = CONCAT(resultado, contador, ', ');
        SET contador = contador + 1;
    END WHILE;

    SELECT resultado AS serie_numeros;
END$$

DELIMITER ;

CALL generar_serie(10);

Ejemplo completo: empleados por departamento

Procedimiento que devuelve los empleados de un departamento específico junto con el salario promedio del mismo:

SQL
DELIMITER $$

CREATE PROCEDURE reporte_departamento(IN depto_nombre VARCHAR(50))
BEGIN
    DECLARE promedio_salario DECIMAL(10,2);

    -- Calcular salario promedio
    SELECT AVG(e.salario) INTO promedio_salario
    FROM empleados e
    INNER JOIN departamentos d ON e.depto_id = d.id
    WHERE d.nombre = depto_nombre;

    -- Mostrar empleados
    SELECT e.id, e.nombre, e.apellido, e.salario,
           e.salario - promedio_salario AS diferencia_promedio
    FROM empleados e
    INNER JOIN departamentos d ON e.depto_id = d.id
    WHERE d.nombre = depto_nombre
    ORDER BY e.salario DESC;

    -- Mostrar resumen
    SELECT depto_nombre AS departamento,
           COUNT(*) AS total_empleados,
           promedio_salario AS salario_promedio;
END$$

DELIMITER ;

CALL reporte_departamento('Ventas');

Los procedimientos almacenados mejoran la seguridad (los usuarios ejecutan el procedimiento sin acceso directo a las tablas), reducen el tráfico de red (la lógica viaja al servidor), y centralizan la lógica de negocio. También permiten reutilización y facilitan el mantenimiento.

Depurar procedimientos almacenados es más difícil que el código de aplicación. MySQL no tiene un depurador integrado; usa SELECT temporales o tablas de log para rastrear valores. Además, los procedimientos pueden ser menos portables entre distintos motores de base de datos.
