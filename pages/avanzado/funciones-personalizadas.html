Funciones personalizadas

Las funciones definidas por el usuario (UDF) permiten extender las capacidades de MySQL creando funciones reutilizables que devuelven un valor escalar. A diferencia de los procedimientos almacenados, las funciones se usan directamente dentro de expresiones SQL, como parte de SELECT, WHERE, SET, etc.

CREATE FUNCTION

La sintaxis para crear una función requiere definir el nombre, los parámetros de entrada, el tipo de retorno y las características como DETERMINISTIC:

SQL
DELIMITER $$

CREATE FUNCTION calcular_edad(fecha_nacimiento DATE)
RETURNS INT
DETERMINISTIC
BEGIN
    DECLARE edad INT;
    SET edad = TIMESTAMPDIFF(YEAR, fecha_nacimiento, CURDATE());
    RETURN edad;
END$$

DELIMITER ;

-- Uso en consulta
SELECT id, nombre, fecha_nacimiento,
       calcular_edad(fecha_nacimiento) AS edad
FROM empleados;

Ejemplos de funciones escalares

SQL
-- Función para formatear nombre completo
DELIMITER $$

CREATE FUNCTION nombre_completo(nombre VARCHAR(50), apellido VARCHAR(50))
RETURNS VARCHAR(101)
DETERMINISTIC
BEGIN
    RETURN CONCAT(nombre, ' ', apellido);
END$$

DELIMITER ;

-- Función para calcular IVA (impuesto)
DELIMITER $$

CREATE FUNCTION calcular_iva(monto DECIMAL(10,2), tasa DECIMAL(5,2))
RETURNS DECIMAL(10,2)
DETERMINISTIC
BEGIN
    RETURN monto * (tasa / 100);
END$$

DELIMITER ;

-- Función para categorizar un salario
DELIMITER $$

CREATE FUNCTION categoria_salario(salario DECIMAL(10,2))
RETURNS VARCHAR(20)
DETERMINISTIC
BEGIN
    IF salario >= 5000 THEN
        RETURN 'Alto';
    ELSEIF salario >= 3000 THEN
        RETURN 'Medio';
    ELSE
        RETURN 'Bajo';
    END IF;
END$$

DELIMITER ;

-- Consulta combinando funciones
SELECT nombre_completo(nombre, apellido) AS empleado,
       salario,
       calcular_iva(salario, 19) AS iva_sobre_salario,
       categoria_salario(salario) AS categoria
FROM empleados;

Manejo de NULLs en funciones

Es buena práctica manejar valores nulos explícitamente para evitar resultados inesperados:

SQL
DELIMITER $$

CREATE FUNCTION tasa_interes_mensual(tasa_anual DECIMAL(5,2))
RETURNS DECIMAL(7,4)
DETERMINISTIC
BEGIN
    IF tasa_anual IS NULL THEN
        RETURN NULL;
    END IF;
    RETURN tasa_anual / 12 / 100;
END$$

DELIMITER ;

SELECT tasa_interes_mensual(12.00);  -- 0.0100
SELECT tasa_interes_mensual(NULL);   -- NULL

DETERMINISTIC vs NOT DETERMINISTIC: Una función es DETERMINISTIC si siempre produce el mismo resultado para los mismos parámetros de entrada (ej: calcular_iva). Es NOT DETERMINISTIC si el resultado puede variar aunque los parámetros sean iguales (ej: una función que usa NOW() o RAND()). Declarar incorrectamente una función como DETERMINISTIC cuando no lo es puede causar resultados incorrectos en replicación y en el uso de índices. MySQL exige al menos una de estas características: DETERMINISTIC, NO SQL o READS SQL DATA para crear funciones. Si usas NOW(), RAND() o CURDATE(), declárala como NOT DETERMINISTIC.

Las funciones personalizadas son ideales para lógica que se repite en múltiples consultas. Sin embargo, ten en cuenta que una función se ejecuta una vez por cada fila del resultado, lo que puede impactar el rendimiento en conjuntos grandes. Para operaciones por lote, considera usar procedimientos almacenados.

Eliminar y ver funciones

SQL
-- Eliminar una función
DROP FUNCTION IF EXISTS calcular_edad;

-- Ver todas las funciones de la base de datos
SHOW FUNCTION STATUS WHERE Db = 'mi_base_datos';

-- Ver la definición de una función
SHOW CREATE FUNCTION nombre_completo;
