Funciones ventana (Window Functions)

Las funciones ventana (window functions) realizan cálculos sobre un conjunto de filas relacionadas con la fila actual, sin colapsar los resultados como hacen GROUP BY y las funciones agregadas. Fueron introducidas en MySQL 8.0 y son esenciales para análisis de datos, reporting y rankings.

¿Qué son las funciones ventana?

Una función ventana opera sobre una "ventana" (window) definida por la cláusula OVER(). A diferencia de GROUP BY, las funciones ventana no agrupan filas en una sola salida — cada fila conserva su identidad y la función agrega un valor calculado.

SQL
-- Sintaxis general
SELECT columna1, columna2,
       funcion_ventana() OVER (
           PARTITION BY columna   -- opcional: divide en particiones
           ORDER BY columna       -- opcional: orden dentro de cada partición
       ) AS resultado
FROM tabla;

ROW_NUMBER() — Numeración de filas

Asigna un número único incremental a cada fila dentro de una partición:

SQL
SELECT nombre, departamento, salario,
    ROW_NUMBER() OVER (ORDER BY salario DESC) AS ranking_global,
    ROW_NUMBER() OVER (PARTITION BY departamento ORDER BY salario DESC) AS ranking_depto
FROM empleados;

RANK() y DENSE_RANK() — Ranking con empates

RANK() asigna el mismo rango a valores iguales, pero salta números después de un empate. DENSE_RANK() no salta números:

SQL
SELECT nombre, departamento, salario,
    RANK() OVER (ORDER BY salario DESC) AS ranking,
    DENSE_RANK() OVER (ORDER BY salario DESC) AS dense_ranking
FROM empleados;

LAG() y LEAD() — Acceso a filas adyacentes

LAG() accede al valor de una fila anterior y LEAD() al de una fila posterior dentro de la ventana:

SQL
SELECT nombre, salario,
    LAG(salario, 1, 0) OVER (ORDER BY salario) AS salario_anterior,
    salario - LAG(salario, 1, 0) OVER (ORDER BY salario) AS diferencia,
    LEAD(salario, 1, 0) OVER (ORDER BY salario) AS salario_siguiente
FROM empleados;

LAG(columna, offset, default) — el segundo parámetro es cuántas filas retroceder (1 por defecto), y el tercero es el valor por defecto si no hay fila anterior.

SUM() OVER — Totales acumulados

Las funciones agregadas como SUM, AVG, COUNT, MIN y MAX también pueden usarse como funciones ventana:

SQL
SELECT nombre, departamento, salario,
    SUM(salario) OVER (PARTITION BY departamento) AS total_depto,
    ROUND(AVG(salario) OVER (PARTITION BY departamento), 2) AS promedio_depto,
    SUM(salario) OVER (ORDER BY salario) AS acumulado_global
FROM empleados;

Frame: ventanas móviles

Puedes definir un frame (marco) dentro de la ventana para limitar las filas consideradas. Esto es útil para medias móviles y totales parciales:

SQL
-- Media móvil de 3 salarios (fila actual + 2 anteriores)
SELECT nombre, salario,
    AVG(salario) OVER (
        ORDER BY salario
        ROWS BETWEEN 2 PRECEDING AND CURRENT ROW
    ) AS media_movil_3
FROM empleados;

-- Total acumulado por departamento
SELECT nombre, departamento, salario,
    SUM(salario) OVER (
        PARTITION BY departamento
        ORDER BY salario
        ROWS UNBOUNDED PRECEDING
    ) AS acumulado_depto
FROM empleados;

Las funciones ventana solo están disponibles en MySQL 8.0+. Si usas MySQL 5.7 o inferior, no podrás utilizar esta funcionalidad. Considera actualizar o simular con variables de usuario.
