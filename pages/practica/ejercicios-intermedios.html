Ejercicios intermedios de SQL

En esta sección practicarás consultas más avanzadas que involucran múltiples tablas, agrupaciones, filtros sobre agregados y subconsultas. Utilizaremos tres tablas relacionadas: clientes, pedidos y productos.

Ejecuta todo el script de creación de tablas antes de comenzar los ejercicios. Puedes copiar cada bloque SQL directamente en MySQL Workbench o DB Fiddle.

Tablas de ejemplo

SQL
CREATE TABLE clientes (
  id INT PRIMARY KEY AUTO_INCREMENT,
  nombre VARCHAR(60),
  ciudad VARCHAR(40)
);

CREATE TABLE pedidos (
  id INT PRIMARY KEY AUTO_INCREMENT,
  cliente_id INT,
  total DECIMAL(10,2),
  fecha DATE,
  FOREIGN KEY (cliente_id) REFERENCES clientes(id)
);

CREATE TABLE productos (
  id INT PRIMARY KEY AUTO_INCREMENT,
  nombre VARCHAR(60),
  precio DECIMAL(10,2),
  categoria VARCHAR(40)
);

Ejercicio 1: INNER JOIN clientes-pedidos

Obtén el nombre del cliente, el total y la fecha de todos los pedidos realizados. Combina las tablas clientes y pedidos con un INNER JOIN. Ordena por fecha descendente.

Ver solución
SQL
SELECT c.nombre, p.total, p.fecha
FROM clientes c
INNER JOIN pedidos p ON c.id = p.cliente_id
ORDER BY p.fecha DESC;

Ejercicio 2: LEFT JOIN con clientes sin pedidos

Obtén todos los clientes, incluyendo aquellos que nunca han realizado un pedido. Muestra el nombre del cliente, ciudad y el total del pedido (como NULL si no tiene). Identifica al cliente sin pedidos.

Ver solución
SQL
SELECT c.nombre, c.ciudad, p.total
FROM clientes c
LEFT JOIN pedidos p ON c.id = p.cliente_id

Ejercicio 3: GROUP BY con SUM total por cliente

Calcula el gasto total de cada cliente sumando el total de todos sus pedidos. Muestra el nombre del cliente y el gasto total. Ordena de mayor a menor gasto.

Ver solución
SQL
SELECT c.nombre, SUM(p.total) AS gasto_total
FROM clientes c
INNER JOIN pedidos p ON c.id = p.cliente_id
GROUP BY c.id, c.nombre
ORDER BY gasto_total DESC;

Ejercicio 4: HAVING para filtrar clientes con gasto alto

Del resultado anterior, muestra únicamente los clientes cuyo gasto total sea mayor a 3500. Usa HAVING para filtrar después de agrupar.

Ver solución
SQL
SELECT c.nombre, SUM(p.total) AS gasto_total
FROM clientes c
INNER JOIN pedidos p ON c.id = p.cliente_id
GROUP BY c.id, c.nombre
HAVING gasto_total > 3500
ORDER BY gasto_total DESC;
nombregasto_total
Roberto Silva6850.00
Luis Torres3800.00
Juan Mendoza3800.00

Ejercicio 5: Subconsulta para producto más caro

Encuentra el producto más caro de la tabla productos usando una subconsulta. Muestra su nombre, precio y categoría.

Ver solución
SQL
SELECT nombre, precio, categoria
FROM productos
WHERE precio = (SELECT MAX(precio) FROM productos);
nombrepreciocategoria
Laptop HP25000.00Electrónica

Verifica siempre tus resultados. En los JOINs, cuenta cuántas filas esperas obtener: un INNER JOIN muestra solo las coincidencias, mientras que LEFT JOIN incluye todas las filas de la tabla izquierda. Practica variando los tipos de JOIN para entender sus diferencias.
