Ejercicios básicos de SQL

Pon a prueba tus conocimientos fundamentales de SQL con estos ejercicios prácticos. Trabajaremos con una tabla de empleados donde aplicarás consultas SELECT, filtros WHERE, ordenamiento, inserciones, actualizaciones y eliminaciones. Cada ejercicio incluye su solución y el resultado esperado.

Antes de empezar los ejercicios, crea la base de datos y la tabla de ejemplo. Puedes practicar online en DB Fiddle usando MySQL 8.0.

Tabla de ejemplo: empleados

Ejecuta este script para crear y poblar la tabla que usaremos en todos los ejercicios básicos.

SQL
CREATE TABLE empleados (
  id INT PRIMARY KEY AUTO_INCREMENT,
  nombre VARCHAR(50),
  apellido VARCHAR(50),
  puesto VARCHAR(50),
  salario DECIMAL(10,2),
  departamento VARCHAR(30),
  fecha_contratacion DATE
);

Ejercicio 1: Filtrar empleados por departamento

Obtén el nombre, apellido, puesto y salario de todos los empleados que trabajan en el departamento de TI. Ordena los resultados por salario de mayor a menor.

Ver solución
SQL
SELECT nombre, apellido, puesto, salario
FROM empleados
WHERE departamento = 'TI'
ORDER BY salario DESC;

Ejercicio 2: ORDER BY y LIMIT

Obtén los 3 empleados con el salario más alto de toda la empresa. Muestra su nombre completo (concatena nombre y apellido), puesto y salario.

Ver solución
SQL
SELECT CONCAT(nombre, ' ', apellido) AS nombre_completo, puesto, salario
FROM empleados
ORDER BY salario DESC
LIMIT 3;

Ejercicio 4: UPDATE de salario

Al empleado Pedro Sánchez se le ha otorgado un aumento del 15%. Actualiza su salario y verifica el cambio. Además, actualiza su puesto a 'Representante Senior de Ventas'.

Ver solución
SQL
UPDATE empleados
SET salario = salario * 1.15, puesto = 'Representante Senior de Ventas'
WHERE nombre = 'Pedro' AND apellido = 'Sánchez';

SELECT * FROM empleados WHERE nombre = 'Pedro' AND apellido = 'Sánchez';

Ejercicio 5: DELETE de empleados antiguos

Elimina todos los empleados que fueron contratados antes del año 2019. Usa SELECT primero para ver qué registros serán afectados, luego ejecuta el DELETE.

Ver solución
SQL
-- Verificar registros antes de eliminar
SELECT * FROM empleados WHERE fecha_contratacion < '2019-01-01';

-- Eliminar los registros
DELETE FROM empleados WHERE fecha_contratacion < '2019-01-01';

-- Verificar que se eliminaron
SELECT * FROM empleados;
