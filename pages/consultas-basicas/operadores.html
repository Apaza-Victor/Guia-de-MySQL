Operadores en SQL

Los operadores en SQL son símbolos o palabras clave que permiten realizar operaciones sobre los datos, ya sean cálculos matemáticos, comparaciones entre valores, evaluaciones lógicas o manipulación de cadenas. Conocer los operadores disponibles y su precedencia es esencial para escribir consultas correctas y eficientes. Esta página sirve como guía de referencia rápida para todos los operadores que ofrece MySQL.

Operadores aritméticos

Los operadores aritméticos se usan para realizar cálculos matemáticos dentro de las consultas, principalmente en la cláusula SELECT o en condiciones WHERE. MySQL sigue la precedencia matemática estándar: multiplicación y división antes que suma y resta. Se pueden usar paréntesis para alterar el orden de evaluación.

OperadorDescripciónEjemploResultado
+SumaSELECT 10 + 5;15
-RestaSELECT 10 - 5;5
*MultiplicaciónSELECT 10 * 5;50
/DivisiónSELECT 10 / 3;3.3333
%Módulo (residuo)SELECT 10 % 3;1

Operadores de comparación

Los operadores de comparación se utilizan principalmente en la cláusula WHERE para filtrar filas. Comparan dos valores y devuelven verdadero (TRUE), falso (FALSE) o NULL. Es importante recordar que cualquier comparación con NULL produce NULL, no TRUE ni FALSE.

!= o <>Distinto deWHERE salario <> 50000
>Mayor queWHERE precio > 1000
<Menor queWHERE stock < 20
>=Mayor o igual queWHERE salario >= 45000
<=Menor o igual queWHERE promedio <= 8.0

Operadores lógicos

Los operadores lógicos permiten combinar múltiples condiciones en una misma cláusula WHERE. AND exige que todas las condiciones sean verdaderas, OR requiere que al menos una lo sea, y NOT invierte el valor de verdad de una condición. La precedencia natural es NOT > AND > OR, por lo que se recomienda usar paréntesis para evitar ambigüedades.

SQL
SELECT nombre, salario, departamento FROM empleados
WHERE (departamento = 'TI' OR departamento = 'Ventas') AND salario > 45000;

Operadores especiales

MySQL proporciona operadores adicionales para casos de uso específicos. LIKE permite búsqueda por patrones en cadenas. IN verifica si un valor pertenece a una lista. BETWEEN evalúa si un valor está dentro de un rango. IS NULL comprueba la ausencia de valor. Estos operadores hacen que las consultas sean más expresivas y concisas que sus equivalentes con operadores básicos.

OperadorDescripciónEjemplo

INPertenece a una lista de valoresWHERE depto IN ('TI', 'RH')
BETWEENDentro de un rango (inclusive)WHERE salario BETWEEN 40000 AND 50000

Operador de concatenación: CONCAT()

A diferencia de otros lenguajes SQL que usan || para concatenar, MySQL utiliza la función CONCAT(). Esta función recibe dos o más argumentos y los une en una sola cadena. Si algún argumento es NULL, el resultado completo es NULL, a menos que se use CONCAT_WS() (concat with separator) que omite valores nulos.

SQL
SELECT CONCAT(nombre, ' - ', departamento) AS descripcion FROM empleados;
descripcion
Ana López - Ventas
Carlos Ruiz - TI
María García - Ventas
José Pérez - TI
Laura Díaz - RH
Pedro Sánchez - Ventas

Para concatenar con un separador que ignora valores NULL, usa CONCAT_WS(separador, cadena1, cadena2, ...). Por ejemplo: CONCAT_WS(' - ', nombre, departamento).

En MySQL, el operador || no realiza concatenación por defecto. Equivale a OR lógico. Si deseas usar || como concatenación, debes habilitar el modo PIPES_AS_CONCAT en la configuración de SQL. La forma portable y recomendada es usar CONCAT().
