WHERE - Filtrando resultados

La cláusula WHERE permite filtrar filas de una consulta según una condición específica. Solo las filas que cumplen la condición pasan a formar parte del resultado. Es una de las herramientas más poderosas de SQL, ya que permite extraer información precisa de conjuntos de datos grandes. Sin WHERE, las consultas devolverían todas las filas de la tabla, lo que rara vez es útil en aplicaciones reales.

Operadores de comparación

Los operadores de comparación permiten evaluar relaciones entre valores. Los más comunes son = (igual), <> o != (distinto), > (mayor que), < (menor que), >= (mayor o igual) y <= (menor o igual). Las condiciones se escriben después de la cláusula WHERE y antes de cualquier cláusula de ordenamiento.

SQL
SELECT nombre, salario FROM empleados WHERE salario > 50000;
nombresalario
Carlos Ruiz52000.00
José Pérez55000.00

BETWEEN

El operador BETWEEN permite filtrar valores que se encuentran dentro de un rango, incluyendo los extremos. Es una forma más legible de escribir columna >= valor1 AND columna <= valor2. Funciona con números, fechas y texto, aunque con texto el orden se determina alfabéticamente.

SQL
SELECT nombre, salario FROM empleados WHERE salario BETWEEN 40000 AND 50000;
nombresalario
Ana López45000.00
María García48000.00
Laura Díaz41000.00

IN

El operador IN permite comparar una columna contra una lista de valores posibles. Es más limpio y eficiente que encadenar múltiples condiciones con OR. La lista de valores se escribe entre paréntesis y separada por comas. Es especialmente útil cuando se conocen los valores exactos que se desea incluir.

SQL
SELECT nombre, departamento FROM empleados WHERE departamento IN ('TI', 'RH');
nombredepartamento
Carlos RuizTI
José PérezTI
Laura DíazRH

LIKE y patrones de búsqueda

El operador LIKE se usa para buscar patrones en cadenas de texto. El símbolo % representa cualquier secuencia de caracteres (incluyendo cero caracteres), mientras que _ representa exactamente un carácter. LIKE no distingue entre mayúsculas y minúsculas en MySQL por defecto cuando se usa con collation utf8_general_ci.

SQL
SELECT nombre FROM empleados WHERE nombre LIKE 'A%';
nombre
Ana López

IS NULL

Para filtrar valores nulos se usa IS NULL. No se puede usar = NULL porque NULL no es un valor, sino la ausencia de él. Cualquier comparación con NULL usando operadores normales siempre produce un resultado desconocido. IS NOT NULL devuelve las filas que tienen un valor asignado.

SQL
SELECT * FROM empleados WHERE salario IS NOT NULL;

AND, OR y NOT

Los operadores lógicos permiten combinar múltiples condiciones. AND requiere que todas las condiciones sean verdaderas. OR requiere que al menos una lo sea. NOT invierte el resultado de una condición. Se pueden agrupar condiciones con paréntesis para controlar el orden de evaluación, similar a las expresiones matemáticas.

SQL
SELECT nombre, salario, departamento FROM empleados WHERE departamento = 'Ventas' AND salario > 40000;
nombresalariodepartamento
Ana López45000.00Ventas
María García48000.00Ventas

Usa paréntesis para agrupar condiciones lógicas combinadas. Por ejemplo: WHERE (departamento = 'TI' OR departamento = 'Ventas') AND salario > 45000 mejora la legibilidad y evita errores de precedencia.

Error común: usar = NULL en lugar de IS NULL. Recuerda que NULL no es un valor, por lo que las comparaciones con = siempre devuelven NULL (falso). Siempre usa IS NULL o IS NOT NULL.
