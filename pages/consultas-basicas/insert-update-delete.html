INSERT, UPDATE y DELETE

Las sentencias INSERT, UPDATE y DELETE forman parte del sublenguaje DML (Data Manipulation Language) de SQL y permiten modificar los datos almacenados en las tablas. Mientras que SELECT solo lee información, estas tres instrucciones permiten crear, modificar y eliminar registros, completando así el ciclo de gestión de datos en MySQL.

Datos de ejemplo: estudiantes

Usaremos la tabla estudiantes para los ejemplos de esta lección.

SQL
CREATE TABLE estudiantes (
  id INT PRIMARY KEY AUTO_INCREMENT,
  nombre VARCHAR(50),
  carrera VARCHAR(40),
  promedio DECIMAL(3,2)
);

INSERT INTO estudiantes VALUES
(1, 'Sofía Martínez', 'Ing. Sistemas', 8.5),
(2, 'Miguel Ángel', 'Medicina', 9.1),
(3, 'Diana Torres', 'Derecho', 7.8),
(4, 'Luis Herrera', 'Arquitectura', 8.9);

INSERT INTO con valores

La forma más común de insertar datos es usando INSERT INTO seguido de la tabla, las columnas (opcional) y la palabra clave VALUES con los valores en el mismo orden. Si se omiten las columnas, se asume que se proporcionan valores para todas las columnas en el orden definido en la tabla. Es buena práctica especificar las columnas para hacer el código más claro y resistente a cambios en la estructura de la tabla.

SQL
INSERT INTO estudiantes (nombre, carrera, promedio)
VALUES ('Carmen Flores', 'Contabilidad', 8.2);

INSERT múltiples filas

MySQL permite insertar varias filas en una sola sentencia separando cada conjunto de valores con comas. Esto es mucho más eficiente que ejecutar múltiples sentencias INSERT individuales, ya que reduce la comunicación entre la aplicación y el servidor de base de datos.

SQL
INSERT INTO estudiantes (nombre, carrera, promedio) VALUES
('Roberto Vega', 'Ing. Sistemas', 7.5),
('Ana Paula Ruiz', 'Medicina', 9.5);

INSERT SELECT

La combinación INSERT ... SELECT permite insertar en una tabla el resultado de una consulta SELECT. Es útil para copiar datos entre tablas, crear tablas de respaldo o poblar tablas de reporte. Las columnas devueltas por el SELECT deben coincidir en cantidad y tipo con las columnas de destino.

SQL
CREATE TABLE becarios AS SELECT * FROM estudiantes WHERE promedio >= 9.0;

UPDATE para modificar registros

La sentencia UPDATE modifica los valores de una o más columnas en las filas que cumplen la condición especificada en WHERE. Sin WHERE, se actualizarían todas las filas de la tabla. Siempre se debe verificar la condición antes de ejecutar un UPDATE, especialmente en producción.

SQL
UPDATE estudiantes SET promedio = 9.2 WHERE nombre = 'Sofía Martínez';

Para verificar el cambio, consultamos los datos actualizados:

SQL
SELECT * FROM estudiantes WHERE id = 1;
idnombrecarrerapromedio
1Sofía MartínezIng. Sistemas9.2

DELETE para eliminar registros

La sentencia DELETE elimina filas de una tabla. Al igual que UPDATE, si se omite WHERE se eliminarán todas las filas. Es importante diferenciar DELETE de TRUNCATE: DELETE elimina filas una por una (puede tener condiciones y activar triggers), mientras que TRUNCATE elimina todas las filas de golpe y reinicia los contadores AUTO_INCREMENT.

SQL
DELETE FROM estudiantes WHERE id = 4;

Siempre ejecuta un SELECT con la misma condición del WHERE antes de hacer un UPDATE o DELETE para verificar qué filas serán afectadas.

¡Cuidado! Un UPDATE o DELETE sin WHERE afecta a TODAS las filas de la tabla. Siempre verifica que tu condición WHERE esté correctamente escrita antes de ejecutar la sentencia.
