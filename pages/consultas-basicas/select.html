SELECT - Consultas básicas

La sentencia SELECT es la instrucción más utilizada en SQL. Permite consultar datos almacenados en una o varias tablas, seleccionando columnas específicas y aplicando filtros, ordenamientos y agrupaciones. Es la puerta de entrada a la manipulación de información en MySQL y dominarla es esencial para cualquier persona que trabaje con bases de datos.

Sintaxis básica de SELECT

La forma más simple de SELECT permite recuperar una o más columnas de una tabla. Se especifican los nombres de las columnas separados por comas, seguidos de la cláusula FROM que indica la tabla de origen. Para este módulo usaremos la tabla empleados con la siguiente estructura y datos.

SQL
CREATE TABLE empleados (
  id INT PRIMARY KEY AUTO_INCREMENT,
  nombre VARCHAR(50),
  salario DECIMAL(10,2),
  departamento VARCHAR(30)
);

INSERT INTO empleados VALUES

(4, 'José Pérez', 55000, 'TI'),
(5, 'Laura Díaz', 41000, 'RH'),
(6, 'Pedro Sánchez', 39000, 'Ventas');

Seleccionar columnas específicas

Para obtener solo los nombres y salarios de todos los empleados, se listan las columnas deseadas después de SELECT. El orden en que se escriben determina el orden en que aparecen en el resultado. Esta proyección de columnas permite mostrar únicamente la información relevante para cada consulta.

SELECT nombre, salario FROM empleados;

Seleccionar todas las columnas con *

El asterisco * es un comodín que representa todas las columnas de la tabla. Aunque es práctico para explorar datos rápidamente, no se recomienda en producción porque puede devolver columnas innecesarias y afectar el rendimiento. Su uso está orientado principalmente a consultas ad-hoc durante el desarrollo.

SELECT * FROM empleados;

Alias con AS

La cláusula AS permite asignar un nombre temporal o alias a una columna o tabla. Los alias son útiles para hacer los resultados más legibles, especialmente cuando se usan expresiones o funciones. La palabra clave AS es opcional; se puede omitir y escribir directamente el alias después de la columna.

SQL
SELECT nombre AS empleado, salario AS sueldo FROM empleados;
empleadosueldo
Ana López45000.00
Carlos Ruiz52000.00
María García48000.00
José Pérez55000.00

DISTINCT para valores únicos

La palabra clave DISTINCT elimina filas duplicadas del resultado, mostrando solo valores distintos para la columna o combinación de columnas seleccionada. Es especialmente útil para conocer los valores únicos presentes en una columna, como los departamentos de una empresa.

SQL
SELECT DISTINCT departamento FROM empleados;

SELECT con expresiones aritméticas

SQL permite realizar operaciones aritméticas directamente dentro de la sentencia SELECT usando los operadores +, -, *, / y %. Estas expresiones se evalúan para cada fila y el resultado puede mostrarse con un alias descriptivo. Esto es útil para cálculos como incrementos salariales, proyecciones o descuentos.

SQL
SELECT nombre, salario, salario * 1.10 AS con_aumento FROM empleados;
nombresalariocon_aumento
Ana López45000.0049500.00

María García48000.0052800.00
José Pérez55000.0060500.00

Pedro Sánchez39000.0042900.00

Usa alias descriptivos con AS cuando trabajes con expresiones o funciones para que las columnas del resultado tengan nombres claros y legibles.

Evita usar SELECT * en aplicaciones en producción. Siempre especifica las columnas que necesitas para mejorar el rendimiento y la claridad del código.
