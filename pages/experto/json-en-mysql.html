JSON en MySQL

Desde MySQL 5.7, el motor incluye soporte nativo para el tipo de dato JSON. Esto permite almacenar documentos JSON directamente en una columna y utilizar funciones especializadas para crear, consultar y modificar datos semiestructurados sin salir del motor de base de datos.

Columnas JSON

Para definir una columna JSON basta con usar el tipo JSON en el CREATE TABLE. MySQL valida automáticamente que el valor insertado sea un JSON válido; de lo contrario rechaza la operación.

SQL
CREATE TABLE productos (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nombre VARCHAR(100) NOT NULL,
    metadatos JSON,
    creado_en TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

Funciones de creación

MySQL provee funciones para construir documentos JSON desde cero o a partir de datos existentes.

SQL
-- JSON_OBJECT: crea un objeto a partir de pares clave-valor
SELECT JSON_OBJECT('nombre', 'Ana', 'edad', 30, 'activo', true);

-- JSON_ARRAY: crea un arreglo JSON
SELECT JSON_ARRAY('rojo', 'verde', 'azul', 42, true);

-- JSON_ARRAYAGG: agrega valores como arreglo desde una consulta
SELECT JSON_ARRAYAGG(nombre) FROM productos;

-- JSON_OBJECTAGG: agrega pares clave-valor desde una consulta
SELECT JSON_OBJECTAGG(id, nombre) FROM productos;

Funciones de consulta

Para extraer valores de un documento JSON se usan JSON_EXTRACT y los operadores abreviados -> y ->>. La notación de ruta emplea $ para la raíz y puntos para la jerarquía.

SQL
-- JSON_EXTRACT: extrae valores con la ruta JSON
SELECT
    nombre,
    JSON_EXTRACT(metadatos, '$.marca') AS marca,
    JSON_EXTRACT(metadatos, '$.especificaciones.ram') AS ram
FROM productos;

-- Operador ->: equivalente a JSON_EXTRACT (devuelve con comillas)
SELECT nombre, metadatos->'$.color' AS color FROM productos;

-- Operador ->>: equivalente a JSON_UNQUOTE(JSON_EXTRACT(...)) (sin comillas)
SELECT nombre, metadatos->>'$.peso' AS peso FROM productos;

-- JSON_UNQUOTE: elimina las comillas del resultado
SELECT nombre, JSON_UNQUOTE(JSON_EXTRACT(metadatos, '$.marca')) AS marca
FROM productos;

-- JSON_CONTAINS: verifica si un valor existe en el JSON
SELECT * FROM productos
WHERE JSON_CONTAINS(metadatos->'$.especificaciones', '"16GB"', '$.ram');

Funciones de modificación

Para actualizar partes específicas de un documento JSON sin reemplazarlo por completo existen las siguientes funciones.

SQL
-- JSON_SET: inserta o reemplaza un valor en la ruta
UPDATE productos
SET metadatos = JSON_SET(metadatos, '$.precio', 1299.99)
WHERE id = 1;

-- JSON_INSERT: inserta solo si la ruta no existe
UPDATE productos
SET metadatos = JSON_INSERT(metadatos, '$.garantia', '2 años')
WHERE id = 1;

-- JSON_REPLACE: reemplaza solo si la ruta existe
UPDATE productos
SET metadatos = JSON_REPLACE(metadatos, '$.color', 'Plata')
WHERE id = 1;

-- JSON_REMOVE: elimina una clave del documento
UPDATE productos
SET metadatos = JSON_REMOVE(metadatos, '$.peso')
WHERE id = 1;

-- JSON_MERGE_PATCH: fusiona objetos JSON (reemplaza claves existentes)
UPDATE productos
SET metadatos = JSON_MERGE_PATCH(metadatos, '{"descuento": 0.1}')
WHERE id = 1;

Índices en columnas JSON

Las columnas JSON no se pueden indexar directamente. Para indexar un campo dentro del JSON se crea una columna generada (generated column) que extrae el valor y luego se indexa esa columna.

SQL
-- Crear columna generada que extrae la marca del JSON
ALTER TABLE productos
ADD COLUMN marca_v VARCHAR(50)
GENERATED ALWAYS AS (JSON_UNQUOTE(JSON_EXTRACT(metadatos, '$.marca'))) STORED;

-- Crear índice sobre la columna generada
CREATE INDEX idx_marca ON productos(marca_v);

-- Ahora las búsquedas por marca usan el índice
SELECT * FROM productos WHERE marca_v = 'TechCorp';

Usa JSON cuando necesites flexibilidad en el esquema (atributos variables) o integres datos de APIs externas. Para datos estructurados y consultados frecuentemente, prefiere columnas normales: obtendrás mejor rendimiento, tipado estricto y la capacidad de indexar directamente.

Ejemplo completo: metadatos flexibles de productos

Imagina un catálogo de productos donde cada categoría tiene atributos distintos. Con JSON puedes almacenarlos sin modificar el esquema.

SQL
-- Consultar productos con precio mayor a 1000
SELECT nombre, metadatos->>'$.precio' AS precio
FROM productos
WHERE CAST(metadatos->>'$.precio' AS DECIMAL(10,2)) > 1000;

-- Listar todas las marcas disponibles
SELECT DISTINCT metadatos->>'$.marca' AS marca FROM productos;

-- Productos con RAM de 16GB
SELECT nombre FROM productos
WHERE JSON_EXTRACT(metadatos, '$.especificaciones.ram') = '"16GB"';

Las columnas JSON incurren en un overhead de almacenamiento y validación. No uses JSON como reemplazo general de columnas normales. Úsalo para datos que cambian de estructura con frecuencia o que se consultan esporádicamente.
