GROUP BY y HAVING

GROUP BY agrupa filas que tienen los mismos valores en columnas específicas, permitiendo aplicar funciones agregadas a cada grupo. HAVING filtra grupos después de la agregación, a diferencia de WHERE que filtra filas antes de agrupar.

GROUP BY con una columna

Agrupemos las ventas por categoría para obtener estadísticas de cada grupo.

SQL
SELECT
  categoria,
  COUNT(*) AS total_productos,
  SUM(cantidad) AS unidades_vendidas,
  ROUND(AVG(precio), 2) AS precio_promedio,
  SUM(cantidad * precio) AS ingreso_total
FROM ventas
GROUP BY categoria;

GROUP BY con varias columnas

Puedes agrupar por múltiples columnas para obtener desgloses más detallados. El orden de las columnas en GROUP BY afecta la forma en que se presentan los resultados.

SQL
-- Agrupar por año y categoría
SELECT
  YEAR(fecha) AS anio,
  categoria,
  SUM(cantidad) AS unidades,
  SUM(cantidad * precio) AS ingreso
FROM ventas
GROUP BY YEAR(fecha), categoria
ORDER BY anio, categoria;

HAVING vs WHERE

WHERE filtra filas antes de la agrupación. HAVING filtra grupos después de la agregación. No puedes usar funciones agregadas en WHERE, pero sí en HAVING.

SQL
-- Filtrar categorías con ingreso total mayor a 5000
SELECT
  categoria,
  SUM(cantidad * precio) AS ingreso_total
FROM ventas
WHERE YEAR(fecha) = 2024
GROUP BY categoria
HAVING SUM(cantidad * precio) > 5000;

-- Error común: no puedes usar SUM en WHERE
-- WHERE SUM(cantidad * precio) > 5000  -- ESTO FALLA

Orden de ejecución en SQL

Es fundamental entender el orden lógico en que MySQL ejecuta las cláusulas: FROM, WHERE, GROUP BY, HAVING, SELECT, ORDER BY, LIMIT. Saber esto te ayuda a escribir consultas correctas y optimizadas.

SQL
-- Orden de ejecución demostrado
SELECT categoria, COUNT(*) AS total
FROM ventas              -- 1. FROM
WHERE precio > 100       -- 2. WHERE (fila individual)
GROUP BY categoria       -- 3. GROUP BY
HAVING COUNT(*) >= 2     -- 4. HAVING (grupo)
ORDER BY total DESC;     -- 5. ORDER BY
categoriatotal
Electrónica4
Muebles2

Error común: Intentar usar WHERE para filtrar funciones agregadas. Recuerda: WHERE se ejecuta antes de GROUP BY, por lo que no puede evaluar agregaciones. Usa HAVING para filtrar grupos y WHERE para filtrar filas individuales antes de agrupar.
