JOINs en MySQL

Los JOINs permiten combinar filas de dos o más tablas basándose en una columna relacionada entre ellas. Son fundamentales para trabajar con bases de datos relacionales y obtener datos que están distribuidos en múltiples tablas.

Tablas de ejemplo

Usaremos las tablas clientes y pedidos para los ejemplos.

SQL
CREATE TABLE clientes (
  id INT PRIMARY KEY,
  nombre VARCHAR(50),
  ciudad VARCHAR(30)
);

CREATE TABLE pedidos (
  id INT PRIMARY KEY,
  cliente_id INT,
  total DECIMAL(10,2),
  fecha DATE,
  FOREIGN KEY (cliente_id) REFERENCES clientes(id)
);

INNER JOIN

Devuelve solo las filas que tienen coincidencia en ambas tablas. Es el tipo de JOIN más común.

SQL
SELECT
  c.nombre,
  c.ciudad,
  p.id AS pedido_id,
  p.total,
  p.fecha
FROM clientes c
INNER JOIN pedidos p ON c.id = p.cliente_id;

LEFT JOIN

Devuelve todas las filas de la tabla izquierda (clientes) y las coincidencias de la tabla derecha (pedidos). Si no hay coincidencia, las columnas de pedidos aparecen como NULL.

SQL
SELECT
  c.nombre,
  c.ciudad,
  p.id AS pedido_id,
  p.total
FROM clientes c
LEFT JOIN pedidos p ON c.id = p.cliente_id;

RIGHT JOIN

Es el inverso de LEFT JOIN: devuelve todas las filas de la tabla derecha y las coincidencias de la tabla izquierda. Es menos común porque se puede reescribir como LEFT JOIN invirtiendo el orden de las tablas.

SQL
SELECT
  c.nombre,
  p.id AS pedido_id,
  p.total
FROM clientes c
RIGHT JOIN pedidos p ON c.id = p.cliente_id;

CROSS JOIN

Producto cartesiano: combina cada fila de la primera tabla con cada fila de la segunda. Útil para generar combinaciones completas, aunque debe usarse con precaución por la cantidad de resultados.

SQL
SELECT c.nombre, p.id AS pedido_id
FROM clientes c
CROSS JOIN pedidos p;
nombrepedido_id
Ana López101
Ana López102
Ana López... (20 filas en total)

Self JOIN

Una tabla se combina consigo misma. Es útil para datos jerárquicos como empleados y jefes, categorías y subcategorías, etc.

SQL
-- Suponiendo una tabla empleados con id, nombre, jefe_id
SELECT
  e.nombre AS empleado,
  j.nombre AS jefe
FROM empleados e
LEFT JOIN empleados j ON e.jefe_id = j.id;
empleadojefe
Pedro SánchezMaría García
Lucía DíazMaría García
María GarcíaNULL

Buenas prácticas: Usa alias de tablas (c, p) para hacer las consultas más legibles. Siempre especifica el tipo de JOIN explícitamente. Prefiere INNER JOIN o LEFT JOIN sobre RIGHT JOIN por claridad. Cuando trabajes con muchas tablas, considera usar vistas para simplificar consultas complejas.
