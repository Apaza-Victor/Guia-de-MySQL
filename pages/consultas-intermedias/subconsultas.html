Subconsultas (subqueries)

Una subconsulta es una consulta anidada dentro de otra consulta. Se escribe entre paréntesis y puede usarse en las cláusulas WHERE, FROM, SELECT, HAVING e incluso dentro de INSERT, UPDATE y DELETE. Las subconsultas permiten resolver problemas complejos dividiéndolos en partes más pequeñas.

Subconsulta escalar en WHERE

Devuelve un único valor y se usa con operadores de comparación (=, >, <, etc.).

SQL
-- Clientes con pedido mayor al promedio
SELECT c.nombre, p.total, p.fecha
FROM clientes c
INNER JOIN pedidos p ON c.id = p.cliente_id
WHERE p.total > (
  SELECT AVG(total) FROM pedidos
);

Subconsulta de múltiples filas con IN

Cuando la subconsulta devuelve varias filas, usamos IN, NOT IN, ANY o ALL.

SQL
-- Clientes que han realizado al menos un pedido
SELECT nombre, ciudad
FROM clientes
WHERE id IN (
  SELECT DISTINCT cliente_id
  FROM pedidos
  WHERE cliente_id IS NOT NULL
);

ANY y ALL

ANY compara un valor con cada elemento devuelto por la subconsulta y devuelve verdadero si alguna comparación es verdadera. ALL requiere que todas las comparaciones sean verdaderas.

SQL
-- Pedidos mayores a cualquier pedido del cliente 1
SELECT * FROM pedidos
WHERE total > ANY (
  SELECT total FROM pedidos WHERE cliente_id = 1
);

-- Pedidos mayores a todos los pedidos del cliente 1
SELECT * FROM pedidos
WHERE total > ALL (
  SELECT total FROM pedidos WHERE cliente_id = 1
);

Subconsultas correlacionadas

Una subconsulta correlacionada hace referencia a columnas de la consulta externa. Se evalúa una vez por cada fila procesada por la consulta externa, lo que puede hacerlas lentas en tablas grandes.

SQL
-- Pedido más caro de cada cliente
SELECT c.nombre, p.total, p.fecha
FROM pedidos p
INNER JOIN clientes c ON p.cliente_id = c.id
WHERE p.total = (
  SELECT MAX(p2.total)
  FROM pedidos p2
  WHERE p2.cliente_id = p.cliente_id
);

Subconsultas en FROM (tablas derivadas)

Una subconsulta en FROM actúa como una tabla temporal (tabla derivada). Debes asignarle un alias obligatoriamente.

SQL
-- Promedio de pedidos por cliente
SELECT
  ROUND(AVG(total_por_cliente), 2) AS promedio_gasto
FROM (
  SELECT cliente_id, SUM(total) AS total_por_cliente
  FROM pedidos
  WHERE cliente_id IS NOT NULL
  GROUP BY cliente_id
) AS resumen;

Subconsulta en SELECT

Puedes usar una subconsulta como una columna calculada en el SELECT. Debe devolver un único valor escalar.

SQL
SELECT
  c.nombre,
  c.ciudad,
  (
    SELECT COUNT(*)
    FROM pedidos p
    WHERE p.cliente_id = c.id
  ) AS total_pedidos,
  (
    SELECT COALESCE(SUM(p2.total), 0)
    FROM pedidos p2
    WHERE p2.cliente_id = c.id
  ) AS gasto_total
FROM clientes c;

Rendimiento: En muchos casos, un JOIN es más eficiente que una subconsulta correlacionada porque MySQL puede optimizar mejor el plan de ejecución. Sin embargo, las subconsultas suelen ser más legibles para problemas específicos. Evalúa cada caso: para agregaciones complejas, las subconsultas en FROM (tablas derivadas) son una excelente opción.
