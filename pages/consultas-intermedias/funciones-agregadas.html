Funciones agregadas (COUNT, SUM, AVG, MIN, MAX)

Las funciones agregadas en MySQL permiten realizar cálculos sobre un conjunto de filas y devolver un único resultado. Son esenciales para el análisis y resumen de datos en cualquier base de datos relacional.

Tabla de ejemplo: ventas

Para los ejemplos de esta página usaremos la siguiente tabla ventas:

SQL
CREATE TABLE ventas (
  id INT AUTO_INCREMENT PRIMARY KEY,
  producto VARCHAR(50),
  categoria VARCHAR(30),
  cantidad INT,
  precio DECIMAL(10,2),
  fecha DATE
);

COUNT

Cuenta el número de filas de un conjunto de resultados. COUNT(*) cuenta todas las filas incluyendo aquellas con valores NULL, mientras que COUNT(columna) solo cuenta las filas donde la columna no es NULL.

SQL
-- Contar todas las ventas
SELECT COUNT(*) AS total_ventas FROM ventas;

-- Contar productos vendidos (no NULL)
SELECT COUNT(producto) AS total_productos FROM ventas;
total_ventas
8

SUM

Suma los valores de una columna numérica. Es muy útil para calcular totales como ingresos, cantidades o cualquier métrica acumulativa.

SQL
-- Calcular el ingreso total por cada producto (cantidad * precio)
SELECT SUM(cantidad * precio) AS ingreso_total FROM ventas;

-- Sumar cantidades vendidas por categoría
SELECT categoria, SUM(cantidad) AS total_unidades
FROM ventas
GROUP BY categoria;

AVG

Calcula el promedio de los valores de una columna numérica. MySQL devuelve un decimal con la mayor precisión posible.

SQL
-- Precio promedio de todos los productos
SELECT AVG(precio) AS precio_promedio FROM ventas;

-- Promedio redondeado a 2 decimales
SELECT ROUND(AVG(precio), 2) AS precio_promedio FROM ventas;
precio_promedio
3124.375000

MIN y MAX

Devuelven el valor mínimo y máximo de una columna, respectivamente. Funcionan con cualquier tipo de dato: numérico, cadena o fecha.

SQL
-- Producto más barato, más caro y rango de fechas
SELECT
  MIN(precio) AS precio_minimo,
  MAX(precio) AS precio_maximo,
  MIN(fecha) AS primera_venta,
  MAX(fecha) AS ultima_venta
FROM ventas;

Cuando uses AVG() con columnas que contienen valores enteros, MySQL devuelve un decimal. Si necesitas controlar la precisión, usa ROUND(AVG(columna), n). Recuerda que COUNT(*) es más rápido que COUNT(columna) cuando solo necesitas saber el número total de filas.
