Gestión de usuarios y permisos

La administración de usuarios y permisos es fundamental para mantener la seguridad de una base de datos MySQL. MySQL ofrece un sistema granular de privilegios que permite controlar qué acciones puede realizar cada usuario sobre cada objeto de la base de datos.

Creación y eliminación de usuarios

Para crear un usuario se utiliza la sentencia CREATE USER, que define el nombre y el host desde el cual puede conectarse. Para eliminarlo se usa DROP USER.

SQL
CREATE USER 'admin'@'localhost' IDENTIFIED BY 'contraseña_segura';
CREATE USER 'lector'@'%' IDENTIFIED BY 'lector2024';

DROP USER 'usuario_obsoleto'@'localhost';

Asignación de privilegios con GRANT

Una vez creado el usuario, se le otorgan permisos mediante GRANT. Se pueden asignar privilegios a nivel global, de base de datos, de tabla o de columna.

SQL
-- Privilegios a nivel de base de datos
GRANT SELECT, INSERT, UPDATE, DELETE ON mi_bd.* TO 'admin'@'localhost';

-- Todos los privilegios sobre una base de datos
GRANT ALL PRIVILEGES ON mi_bd.* TO 'superuser'@'localhost';

-- Privilegios solo sobre columnas específicas
GRANT SELECT (nombre, email) ON mi_bd.clientes TO 'lector'@'%';

-- Acceso de solo lectura a todas las bases de datos
GRANT SELECT ON *.* TO 'reportes'@'localhost';

MySQL dispone de una amplia variedad de privilegios que se adaptan a distintos niveles de acceso. La siguiente tabla resume los más utilizados:

Revocación de privilegios con REVOKE

Para retirar permisos previamente otorgados se utiliza REVOKE. La sintaxis es similar a GRANT.

SQL
-- Revocar un permiso específico
REVOKE DELETE ON mi_bd.* FROM 'admin'@'localhost';

-- Revocar todos los permisos de un usuario
REVOKE ALL PRIVILEGES ON *.* FROM 'usuario_externo'@'%';

Visualización de privilegios

Para ver los privilegios asignados a un usuario se usa SHOW GRANTS. Esto resulta útil para auditar permisos o depurar problemas de acceso.

SQL
SHOW GRANTS FOR 'admin'@'localhost';

-- Ver privilegios del usuario actual
SHOW GRANTS FOR CURRENT_USER();
Grants for admin@localhost
GRANT USAGE ON *.* TO `admin`@`localhost`
GRANT SELECT, INSERT, UPDATE, DELETE ON `mi_bd`.* TO `admin`@`localhost`

FLUSH PRIVILEGES

Después de modificar los privilegios con GRANT o REVOKE, MySQL recarga automáticamente las tablas de permisos. Sin embargo, si se editan directamente las tablas del sistema (mysql.user, mysql.db, etc.), es necesario ejecutar FLUSH PRIVILEGES para que los cambios surtan efecto.

SQL
FLUSH PRIVILEGES;

Roles en MySQL 8

A partir de MySQL 8.0 se introdujeron los roles, que permiten agrupar un conjunto de privilegios y asignarlos fácilmente a múltiples usuarios. Los roles simplifican la administración cuando se manejan muchos usuarios con perfiles similares.

SQL
-- Crear un rol
CREATE ROLE 'lector_rol';

-- Asignar privilegios al rol
GRANT SELECT ON mi_bd.* TO 'lector_rol';

-- Asignar el rol a un usuario
GRANT 'lector_rol' TO 'juan'@'localhost';

-- Activar el rol por defecto al iniciar sesión
SET DEFAULT ROLE 'lector_rol' TO 'juan'@'localhost';

Siempre aplica el principio de mínimo privilegio: asigna únicamente los permisos necesarios para que cada usuario realice su trabajo. Evita usar ALL PRIVILEGES en usuarios de producción y revisa periódicamente los permisos con SHOW GRANTS.
